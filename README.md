# Rahul & Deepti — Wedding Invitation Website

A responsive, single-page wedding invitation built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser. Keep the `images` folder beside it; the couple portraits are stored locally in WebP format.

## Included
- Full-screen 9:16 royal palace doors that open slowly to reveal a couple portrait and wedding message
- Maroon, ivory, and gold palette with Indian toran, diya, and ornamental details
- Two couple portraits with responsive frames, subtle scroll-linked zoom and reveal animations
- Animated SVG gathbandhan (sacred wedding knot) section that ties together as it enters view
- Live countdown and scratch-to-reveal date card
- Haldi and wedding event cards, family section, venue map link, and invitation sharing
- Mobile navigation and reduced-motion support

## Details to confirm before publishing
- Wedding ceremony time (the countdown currently targets midnight IST on 26 November 2026)
- Haldi venue and time
- Any wording or family-side attribution you want added

This is a static site; no build tools or server are required. For public hosting, upload `index.html` and the complete `images` folder together.
